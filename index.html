الهدف

تدريب الطلبة على تصميم قاعدة بيانات MySQL، بناء REST API باستخدام FastAPI وتنفيذ CRUD، اختبار الـ API باستخدام Swagger وPostman، ثم ربطه بواجهة HTML/CSS باستخدام JavaScript Fetch API.

User → HTML/CSS → JavaScript Fetch API → FastAPI REST API → MySQL

مهم: لا تتصل واجهة HTML بقاعدة MySQL مباشرة؛ جميع العمليات تمر عبر FastAPI.

متطلبات Postman والواجهة

Postman

  • Collection باسم المشروع.
  • اختبار POST وGET وPUT/PATCH وDELETE.
  • اختبار البحث والتصفية.
  • اختبار بيانات ناقصة أو خاطئة وID غير موجود.
  • حفظ جميع Requests للتسليم.

HTML / CSS / JavaScript

  • Form للإضافة.
  • Table يعرض البيانات القادمة من FastAPI.
  • Edit وDelete.
  • Search أو Filter.
  • رسائل نجاح وخطأ.
  • استخدام Fetch API للربط الحقيقي مع Backend.
